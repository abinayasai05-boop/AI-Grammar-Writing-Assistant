# ✍️ AI Grammar & Writing Assistant

An AI-powered NLP application that helps users improve their English writing by detecting grammar and spelling mistakes, suggesting corrections, and analyzing writing quality.

## 🚀 Features

- ✅ Grammar correction
- ✅ Spelling error detection
- ✅ Writing improvement
- ✅ Correction suggestions
- ✅ Writing quality score
- ✅ Word count
- ✅ Sentence count
- ✅ Error analysis
- ✅ Interactive web interface

## 🛠️ Technologies Used

- Python
- Google Colab
- Natural Language Processing (NLP)
- LanguageTool
- Gradio
- Regular Expressions

## ⚙️ How It Works

1. User enters English text.
2. The application analyzes the text using NLP.
3. Grammar and spelling errors are detected.
4. Suggested corrections are generated.
5. The corrected text is displayed.
6. A writing score and analysis are provided.

## 📊 Example

### Input

```text
I am a student and I wants to improve my English writing.
I have many mistake in grammar and spelling.
```

### Output

```text
I am a student and I want to improve my English writing.
I have many mistakes in grammar and spelling.
```

The application also displays detected errors, suggested corrections, word count, sentence count, and writing score.
